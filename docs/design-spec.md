# UI 设计规范

## 设计原则

- **简洁**：减少视觉噪音，每个元素有明确目的
- **直观**：不需要教程，一眼就会用
- **轻盈**：白色为主，不喧宾夺主

## 色彩

| 用途 | 色值 | 说明 |
|------|------|------|
| 窗口背景 | `#FFFFFF` (白色) | 主背景 |
| 卡片背景 | `#F5F5F5` 或 `Color.gray.opacity(0.08)` | 略微灰底区分卡片和背景 |
| 卡片悬停 | `#EBEBEB` 或 `Color.gray.opacity(0.15)` | 鼠标悬停时高亮 |
| 主文字 | `#1A1A1A` 或 `.primary` | 内容文字 |
| 次要文字 | `#8E8E93` 或 `.secondary` | 时间戳、预览 |
| 分隔线 | `#E5E5EA` 或 `Color.gray.opacity(0.2)` | 卡片间分隔 |
| 强调色 | 系统蓝 `#007AFF` | 置顶图标、选中状态 |
| 危险色 | 系统红 `#FF3B30` | 删除按钮 |

## 字体

| 用途 | 字体 | 大小 | 粗细 |
|------|------|------|------|
| 搜索框文字 | SF Pro | 14pt | Regular |
| 卡片内容 | SF Pro | 13pt | Regular |
| 卡片时间 | SF Pro | 11pt | Regular |
| 置顶区标签 | SF Pro | 11pt | Medium |
| 空状态提示 | SF Pro | 14pt | Regular |

## 布局尺寸

| 元素 | 尺寸 |
|------|------|
| Popover 窗口 | 宽 360pt，高 480pt |
| 搜索框高度 | 36pt |
| 卡片高度 | 文字卡片 52pt，图片卡片 80pt |
| 卡片内边距 | 水平 12pt，垂直 8pt |
| 卡片圆角 | 8pt |
| 缩略图尺寸 | 文字：无；图片：宽 48pt，高 48pt |
| 置顶图标 | 12x12pt |
| 删除按钮 | 16x16pt |

## 界面结构

```
┌──────────────────────────────────┐
│          🔍 搜索历史...          │  ← 搜索框
├──────────────────────────────────┤
│  📌 置顶                         │  ← 置顶区标签（有置顶内容时才显示）
│  ┌──────────────────────────┐   │
│  │ 📝 这是置顶的内容...    ⭐ │   │  ← 置顶卡片
│  │    2分钟前               🗑 │   │
│  └──────────────────────────┘   │
├──────────────────────────────────┤
│  ┌──────────────────────────┐   │
│  │ 📝 刚刚复制的内容...    📌 │   │  ← 历史卡片
│  │    1分钟前               🗑 │   │
│  └──────────────────────────┘   │
│  ┌──────────────────────────┐   │
│  │ 🖼 [缩略图] 截图_xxx.png 📌 │   │  ← 图片卡片
│  │    5分钟前               🗑 │   │
│  └──────────────────────────┘   │
│         ...更多卡片...            │
└──────────────────────────────────┘
```

## 交互行为

### 点击卡片
- 文字卡片：内容粘贴到当前应用 → 窗口收起
- 图片卡片：图片粘贴到当前应用 → 窗口收起

### 置顶按钮
- 点击 ⭐/📌 切换置顶状态
- 置顶后卡片移到顶部置顶区
- 取消置顶后回到历史区原位

### 删除按钮
- 点击 🗑 → 卡片从列表移除 → 数据库中删除
- 不需要二次确认（可撤销功能后续版本考虑）

### 搜索
- 输入即搜索，实时过滤
- 清空搜索框恢复完整列表
- 无匹配结果时显示 "无匹配结果"

### 滚动
- 列表支持平滑滚动
- 大量数据时使用 LazyVStack 保证性能

## 动画

- 卡片出现：轻微淡入（opacity 0→1，duration 0.2s）
- 卡片删除：左滑消失
- 置顶切换：卡片平滑移动到新位置
- 窗口弹出/收起：系统默认 Popover 动画
