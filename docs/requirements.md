# 需求规格说明

## 产品概述

**ClipboardHistory** — macOS 菜单栏剪贴板历史管理工具。

自动记录用户复制的一切内容（文字 + 图片），支持按时间线回溯、搜索、再次粘贴。轻量、本地运行、不上传数据。

## 用户画像

- 日常办公用户：经常复制粘贴，偶尔需要找回之前复制过的内容
- 非技术用户：操作直观，不需要学习成本

## 功能需求

### F1：自动记录剪贴板
- 系统每次复制（Cmd+C）时自动捕获内容
- 支持纯文本和图片两种类型
- 连续复制完全相同内容时去重（只保留一条）
- 后台静默运行，不打断用户

### F2：历史浏览
- 菜单栏图标点击弹出历史窗口
- 卡片式列表，每条显示内容预览和时间
- 按时间降序排列（最新在上）
- 置顶条目始终排在最上方，有视觉分隔
- 空状态时显示友好提示

### F3：搜索
- 搜索框实时过滤文字内容
- 模糊匹配（包含关键词即命中）
- 搜索结果保持时间降序

### F4：粘贴
- 点击文字卡片：内容粘贴到当前活动应用光标位置
- 点击图片卡片：图片粘贴到当前活动应用
- 粘贴后窗口自动收起

### F5：置顶与管理
- 每条记录可置顶/取消置顶
- 每条记录可删除
- 删除操作有确认机制（可选）

### F6：存储时长设置
- 选项：1天 / 3天 / 5天 / 7天 / 永久
- 到期自动清理过期记录
- 清理在 App 启动和每次新增记录时触发

### F7：全局快捷键
- 默认 Cmd+Shift+V 弹出/收起历史窗口
- 快捷键可在设置中自定义（后续版本）

### F8：开机自启
- App 随 macOS 登录自动启动
- 可在设置中开关

## 非功能需求

- **性能**：500+ 条记录时列表滚动不掉帧
- **隐私**：所有数据仅存储本地，不上传网络
- **可靠性**：剪贴板监听不丢失、不崩溃
- **兼容性**：macOS 13 (Ventura) 及以上

## 不在此版本范围内

- iCloud 同步
- 多设备同步
- 富文本格式保留
- 文件复制记录
- 快捷键自定义界面
